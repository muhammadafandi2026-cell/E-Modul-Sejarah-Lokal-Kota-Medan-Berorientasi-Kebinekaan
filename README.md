# E-Modul-Sejarah-Lokal-Kota-Medan-Berorientasi-Kebinekaan
E-Modul interaktif Sejarah Lokal Kota Medan masa kolonial dan pendudukan Jepang, berorientasi kebinekaan untuk meningkatkan hasil belajar kognitif sejarah siswa kelas XI. Dilengkapi materi digital, sumber sejarah, foto, peta, lini masa, aktivitas analisis dan evaluasi pembelajaran.
